# Dexer's Chat

**Dexer's Chat** is a simple messaging application with a graphical user interface, developed in Python using Flet. The application allows users to register, log in, and exchange messages in real-time.

## Key Features

- **Registration and Authentication:** Users can register, log in, and remember their credentials.
- **Settings:** Allows users to change their username and select the interface theme (light, dark, or system).
- **Chat:** Send messages in the chat, update usernames, and receive notifications when new participants join.

## Technologies

- **Flet** — A framework for building user interfaces in Python.
- **SQLite** — A lightweight database for storing user data.
- **Base64** — Used for encrypting user credentials.
